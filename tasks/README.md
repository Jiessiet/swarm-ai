# Collaborative research environment

Swarm Chamber currently exposes one workflow. `hackathon/` contains its
instructions, structured action/output schemas, deterministic demo, mediated
web research and execution rules. The directory and event identifiers retain
older names so saved trajectories remain compatible.

Agents receive a configurable objective, current role instructions, graph-filtered
history, source records and feedback. They can request search/read actions and
publish contributions before final synthesis. Live changes apply to the next
decision; the synthesizer follows the same information restrictions.

To add a genuinely different task, define its observation, action validation,
stopping/scoring rules and output format explicitly. An edited research objective
does not grant agents arbitrary tools or change the final research-brief schema.
